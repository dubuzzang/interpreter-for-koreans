# Tercüman — 한국어 · 튀르키예어 · 영어 · 일본어 · 중국어 통역

말하면 바로 통역해서 상대 언어로 읽어 주는 웹앱입니다. 휴대폰 브라우저에서 바로 쓰고, 안드로이드 앱(APK)으로 설치하거나 홈 화면에 추가하면 앱처럼 열립니다.

**바로 쓰기 → https://interpreter-for-koreans.pages.dev/**

- 다섯 언어(한국어 · 튀르키예어 · 영어 · 일본어 · 중국어)끼리 어느 쪽으로든 통역합니다. 중국어는 **간체(중국 본토, zh-CN)** 입니다 — 타오바오·1688 판매자와 이야기할 때.
- **언어 설정**: 오른쪽 위 🌐 버튼(예: `🌐 KO`)을 누르고 한국어 · Türkçe · English · 日本語 · 中文 중에서 고르면, 새로 고침 없이 화면 전체가 그 언어로 바뀌고 이 기기에 저장됩니다(설정 → "언어 / Language"도 같음). 고른 언어가 **'나'의 언어**가 됩니다 — 대화·마주 보기의 '나' 버튼(받아쓰기 · 번역 · 읽어 주기), 글 번역의 기본 방향, 표현집의 내 말 쪽, 기록 표시. 상대 언어는 나머지 네 언어 중에서 고릅니다(상대가 새 내 언어와 같아지면 서로 바꿈).
  - 처음 쓰는 사람: 브라우저 언어가 다섯 언어 중 하나면 그 언어(zh-TW 등도 중국어), 아니면 English. 이미 쓰던 사람(저장된 설정·기록이 있음)은 한국어 그대로.
  - 화면 문구는 모두 `public/js/i18n.js` 한곳에 있습니다. 서버는 한국어 오류 문장과 함께 오류 코드(`code`)를 보내고, 화면은 코드로 고른 언어 문장을 보여 줍니다.
- **읽는 법**은 보는 사람이 읽을 수 있는 글자로 보여 줍니다.

  | 보는 사람 | 한국어 | 튀르키예어 | 영어 | 일본어 | 중국어 |
  |---|---|---|---|---|---|
  | 한국어 사용자 | — | 한글 발음 (Merhaba → 메르하바) | — | 한글 발음 (こんにちは → 곤니치와) | 한글 발음 + 병음 (你好 → 니 하오 / Nǐ hǎo) |
  | 튀르키예어·영어 사용자 | 로마자 (안녕하세요 → Annyeonghaseyo) | — | — | 로마자 (こんにちは → Konnichiwa) | 병음 |
  | 일본어 사용자 | 로마자 | — | — | — | 병음 |
  | 중국어 사용자 | 로마자 | — | — | 로마자 | — |

  일본어는 한자 읽기가 필요해서 서버(`/api/kana`)에서 히라가나 읽기를, 중국어는 서버(`/api/pinyin`)에서 병음을 받아 바꿉니다(병음 음절 수가 한자 수와 맞는 답을 고름). 중국어 한글 발음은 국립국어원 외래어 표기법의 중국어 표를 따릅니다(Běijīng → 베이징, xièxie → 셰셰, duōshao → 둬사오). 표현집은 읽기·병음을 미리 넣어 두어 인터넷 없이도 보입니다. 마주 보기의 각 절반도 그쪽 사람 기준입니다.
- **업데이트 버튼**: 새 버전을 배포하면 열려 있는 앱 위에 "업데이트" 알림이 뜨고(저장된 언어로), 누르면 바로 바뀝니다(설정 → 업데이트 확인). 알림 코드는 `index.html` 안에 있어서(페이지는 늘 새로 받음) 예전 버전 앱에서도 뜹니다.
- **자동 감지**(글 번역): 한글 → 한국어, 가나가 있으면 일본어, 한자만 있으면 중국어 쪽(駅·東京처럼 일본 글자체면 일본어, 어느 쪽 글자도 없으면 중국어 — 일본어 대화 중이면 일본어).
- **답장 추천 · 합의 내용 요약은 숫자를 지어내지 않습니다**: 서버(`lib/assist-core.mjs`)가 답 안의 숫자(아라비아 숫자 · 한자 숫자 一百五 · 한국어 백 개/두 개/이틀 · 튀르키예어 yüz elli · 영어 two hundred · 일본어 ふたつ)를 값으로 바꿔, 대화(원문 · 번역)에 나온 값이 아니면 그 답(요약은 그 칸)을 버립니다. ○○ · ___ · XX 같은 빈칸도 버립니다. 답장 추천은 설정에서 끌 수 있습니다.
- 말투: 존댓말 / 반말 — 번역되는 쪽 언어에 맞게(한국어 존댓말·반말, 일본어 です·ます·タメ口, 튀르키예어 siz·sen, 중국어 您·你, 영어는 영향 없음). 최근 대화를 맥락으로 함께 보내 대명사·생략을 자연스럽게 옮깁니다.

### 번역 엔진 (2026-10-08 비교)

한·튀·영 예문 7개를 모델마다 번역해 비교했습니다.

| 모델 | 결과 |
|---|---|
| **Gemma 4 26B (생각 끔)** | 가장 자연스러움, 1~1.5초 → 기본 |
| Gemma 4 (생각 켬) | 5~17초, 빈 답도 나옴 → `chat_template_kwargs.enable_thinking=false` 필수 |
| Qwen 3.8 27B | 자연스럽지만 튀르키예어 격조사 실수(otobüsü binmek), 1~29초로 들쭉날쭉 |
| Llama 3.3 70B | 무난, 고유명사 실수(Taksim → 택심) → 1차 예비 |
| Mistral Small 3.1 | 가장 빠름(1초), 튀르키예어 문법 실수가 더 많음 → 2차 예비 |
| m2m100 1.2B (번역 전용) | 뜻이 틀림(매워요 → "Bu çok basit") → **쓰지 않음**. 틀린 통역보다 오류 안내가 낫다 |

모델마다 9~12초 제한, 실패·빈 답·글자 체계가 틀린 답이면 다음 모델로 넘어갑니다. Workers AI 무료 사용량(하루 10,000 뉴런)을 다 쓰면 "오늘 무료 번역 한도" 안내가 나옵니다.

한 번에 쓰는 양(2026-10-12 Gemma 4, Workers AI 응답의 `usage`): 번역 약 220~310토큰 ≈ **2~3.4 뉴런**, 답장 추천 약 420~520토큰 ≈ **5.5~7 뉴런**(상대 말마다 한 번), 합의 내용 요약 약 340~610토큰 ≈ **4~8.5 뉴런**(공유할 때 켠 경우만). 답장 추천을 켜 두면 대화 하나에 드는 AI 사용량이 대략 2배가 됩니다.

## 개발

```powershell
npm test                 # 단위 테스트 (가짜 AI로 API까지)
npm run dev              # 로컬 서버 http://127.0.0.1:8788 (AI는 Cloudflare 계정으로 실제 호출)
npm run build:sw         # public/ 파일을 바꾼 뒤 서비스 워커 갱신
npm run deploy           # Cloudflare Pages 배포 (wrangler 로그인 필요)
```

- 버전을 올릴 때: `package.json`·`public/js/version.js`·`CHANGELOG.md`를 함께 바꾸고 `npm run build:sw`.
- 화면 문구를 더할 때: `public/js/i18n.js`의 다섯 언어 사전에 같은 키로 넣고 `t('키')`로 씁니다. 테스트가 다섯 사전의 키·빈 문구·`{채울 자리}`가 같은지, 화면 코드에 한국어 문장을 직접 쓰지 않았는지 확인합니다.
- GitHub Actions는 테스트만 돌립니다. 배포는 번역 API(Pages Functions + Workers AI)가 필요해서 Cloudflare Pages로만 합니다.

## 개인정보

말한 내용과 글은 번역 · 인식 · 답장 추천 · 요약을 위해 Cloudflare Workers AI로 보내고, 서버에 저장하지 않습니다. 통역 기록 · 설정 · 내 표현은 이 기기(localStorage)에만 남습니다. 공유는 사용자가 고른 앱(카톡 · 메일)으로 직접 보내는 것이고, 이 앱 서버를 거치지 않습니다.
